# Nikami TTR addons

| Mod | Source | Current download |
| --- | --- | --- |
| Filthy Casual TTR - seated controls, selectors, hands, physical reload parts, optional tutorial | [Repository](https://github.com/nikamigaming-create/filthy-casual-ttr) | [1.6.0-dev.1 for TTR 1.1](https://github.com/nikamigaming-create/filthy-casual-ttr/releases/tag/v1.6.0-dev.1) |
| Filthy Casual Pool - standalone optional pool addon | [Pool source](https://github.com/nikamigaming-create/filthy-casual-ttr/tree/main/pool-vr) | [0.2.0 beta for TTR 1.1](https://github.com/nikamigaming-create/filthy-casual-ttr/releases/tag/pool-v0.2.0-beta) |
| TTR Meta Link - direct Meta Link / Air Link compatibility | [Repository](https://github.com/nikamigaming-create/ttr-meta-link) | [1.1.0 beta for TTR 1.1](https://github.com/nikamigaming-create/ttr-meta-link/releases/tag/v1.1.0-beta) |

Each addon is optional. Pool requires the separately installed
[Pool Tables Of The Mojave v4](https://www.nexusmods.com/newvegas/mods/100097)
and working TTR; it does not require the seated addon or Meta Link helper.
Original game and TTR files are not distributed. All three current downloads
are prereleases; the weapon tutorial is incomplete.
