# Filthy Casual TTR 1.4.5 beta + standalone Filthy Casual Pool

Choose either addon independently:

- **Filthy-Casual-TTR-1.4.5.zip**: seated height, weapon/aid selectors, native
  right-hand handoff, reload-mode switching, gestures and sticky food-to-mouth.
  Requires a working supported TTR setup. Install via MO2 below TTR.
- **Filthy-Casual-Pool-0.1.0-beta.zip**: standalone VR pool and Sunny at the
  Prospector Saloon. Requires working TTR and
  [Pool Tables Of The Mojave v4](https://www.nexusmods.com/newvegas/mods/100097),
  installed separately. Filthy Casual TTR and our Meta Link helper are NOT required.
  After installing the ZIP in MO2, open its folder and run `Prepare-Pool.cmd` once,
  selecting the original pool mod folder; then enable our addon below the original.
- **Filthy-Casuals-Mobile.mp4**: portrait showcase, 1m56s, approximately 14MB.
  Shows features from BOTH optional addons; pool-only does not add selectors
  or seated controls. Newly authored Sunny motion and actual game-eye footage.

If combining pool with the seated addon, update the seated addon to 1.4.5 or newer.
Pool uses one authoritative input path and releases its controls on exit.

The original mods are linked, not bundled. No TTR binary, original pool assets,
original ESP, personal save or development runtime is included. Three integration
scripts are generated locally from hash-verified original files. Setup never
changes the original mod. Credit: KUPOkinz/TTR and Luke2172/original pool.

Verified locally: standalone pool with the seated addon absent; combined physical
stroke, tracking-loss rejection, normal camera/exit, preserved height/reload,
both selector finger poses, weapon equip, reload toggling and settings afterward.
Food consumption uses the native effect and consumes one item; native grip mode
retains native behavior. Latest headset comfort and a full completed pool match
remain unverified. This is a beta; see docs/VALIDATION.md for precise coverage.

Supported TTR SHA256:
`C9D047D4199C0458281D341AC9DC438A7C928999E19CDAD6F327F8A439A7F9EB`.
Back up your INI before upgrading. Default packages contain neutral height,
automatic reload and quiet selector hints. Graphics/Link settings stay separate.
