# Filthy Casual TTR 1.8.0-beta.4-rc.22

- Installs as one MO2 mod with the original dependencies listed on the [front page](README.md#vehicle-downloads).
- Includes the native scripts required by the vehicle module.
- Uses the stock Roadster’s wheel and tyre pivots for physical steering and arcade handling.
- Mounts the installed Vertibird interior in flight and adds independent Filthy cyclic and collective handles.

## Changes since public RC8

- **Settings moved onto both devices.** FILTHY has its own fourth category on the wrist and full-size Pip-Boy. The same settings follow you between them. The wrist returns hand input to TTR when lowered.
- **Equipment gained profiles and kits.** Save both wheels and holster positions, preview items, and apply them together. The forearm holster keeps its preview clear of the sleeve.
- **Walking, running and sprinting have adjustable zones.** Set each threshold on the device.
- **The flashlight projects onto the world.** The local shadow pass handles grass, trees, saloon glass, bridge railings and signs.
- **Optional vehicles use the original mods.** Grip the stock Roadster rim to steer, use the triggers to accelerate or brake, and release them to coast. Board the Vertibird through Pilot Inside and use the fitted cyclic and collective. Creature riding uses the base TTR setup.

The controls book, core wheels, remapping, seated calibration and bottle effects carry forward from RC8. Voice uses TTR recognition.

Flashlight and Wrist-Boy checks ran in the simulator at native resolution. Headset and upscaling checks are pending.
