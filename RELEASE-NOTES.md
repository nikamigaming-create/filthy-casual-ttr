# Filthy Casual TTR 1.6.0-dev.1 - TTR 1.1 development snapshot

Current seated controls, floating weapon/consumable selectors, native handoff,
finger gestures, height persistence, physical dropped reload parts, and optional
in-world reload guide. Triple-tap left Menu toggles the guide; it starts off.

Install the ZIP through MO2 below TTR and enable Filthy Casual Reload Parts.esp.
Preserve your personal SeatedControls.ini when updating. Requires the exact TTR
1.1 DLL listed in docs/INSTALL.md and the original mod's normal dependencies.

**Tutorial coverage is incomplete:** the current mobile guide covers ten weapon
examples; Fat Man, missile launchers, heavy ammo/power packs and other special
weapons are not yet demonstrated. Flamer/recharger manual guides remain unmapped.
See docs/WEAPON-TUTORIAL.md, docs/TUTORIAL-COVERAGE.json and docs/VALIDATION.md.

The phone tutorial is attached as a partial guide. All original dependencies are
linked, not bundled. Pool and Meta Link are separate optional downloads; see
[all mods](https://github.com/nikamigaming-create/filthy-casual-ttr/blob/main/docs/ALL-MODS.md).
