# Filthy Casual TTR 1.4.4 beta

A separate MO2 addon for KUPOkinz's A Tale of Two Realities: floating touch
selectors for weapons and consumables, native right-hand item handoff, a neutral
center bottle cap, seated height, reload-mode switching and free-hand gestures.

**Install:** download `Filthy-Casual-TTR-1.4.4.zip`, install it using MO2's archive
installer, enable it below TTWVR, and launch your usual modded game entry.
The base mod and its dependencies are required and are not included.

- Weapons: keep the left stick touched and double-tap the right thumbrest.
- Consumables: keep the right stick touched and double-tap the left thumbrest.
- Touch a preview to select; touch the center cap to clear the hand.
- Left Menu tap changes reload mode; hold one second for height/settings.
- Squeeze the right grip to return the selected item to native holding behavior.
- Free fingers remain animated in both wheels while accidental grabs are blocked.

Left Menu intentionally replaces its native gameplay action. The latest finger
revision passed simulator/runtime checks but still awaits physical-headset
approval. Ordinary held-food consumption remains unverified; there is no added
Y-consume command. Native Stimpak use is retained. This is a beta, not a claim of
complete hardware coverage. See README and docs/VALIDATION.md.

Supports TTWVR SHA-256:
`C9D047D4199C0458281D341AC9DC438A7C928999E19CDAD6F327F8A439A7F9EB`.

The ZIP contains neutral settings: zero height offset, popup hints off, automatic
reload enabled. Back up your INI before upgrading. Graphics settings are separate.

[TTR Meta Link companion](https://github.com/nikamigaming-create/ttr-meta-link/releases/tag/v1.0.0)
provides the optional direct Meta OpenXR route. Use either or both addons.
